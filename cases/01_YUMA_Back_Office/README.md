# YUMA Back Office — визуальная система и редизайн

**Категория:** Digital product · UI design · Design system
**Компания:** YUMA / YUMAPOS — B2B SaaS для автоматизации ресторанов
**Формат:** in-house

## Коротко
Обновила визуальный язык бэк-офиса YUMA и собрала из него масштабируемую систему интерфейса: компоненты, состояния, семантическая палитра и гайды по применению.

## Контекст
Бэк-офис YUMA — большой цифровой продукт с множеством разделов и сценариев для управления рестораном. Нужно было обновить его визуальный язык и сделать систему интерфейса более цельной и масштабируемой.

## Задача
Разработать новую визуальную концепцию бэк-офиса, которую можно последовательно применять на большом количестве страниц и сценариев. Обновить набор интерфейсных компонентов и правила их использования.

## Моя роль
Отвечала за визуальную концепцию и UI-дизайн бэк-офиса, разработку компонентов и их состояний, цветовую семантику и документацию по использованию новых решений.

## Решение
- Разработала общую визуальную концепцию интерфейса и масштабировала её на множество страниц продукта.
- Создала и обновила набор компонентов, продумала их состояния и правила применения.
- Отдельно разработала семантическую цветовую палитру, чтобы цвета последовательно использовались для разных ролей и состояний интерфейса.
- Для новых компонентов подготовила гайды, которые описывают их поведение и правила использования и помогают сохранять целостность системы при дальнейшей работе над продуктом.

## Результат
Сформирована единая визуальная система для бэк-офиса, которую можно масштабировать на новые страницы и сценарии. Новые компоненты и гайды создали основу для более последовательной и самостоятельной работы команды с интерфейсом.
